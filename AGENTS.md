## Tools

### Rslint

- Run `yarn run lint` to lint your code

### ESLint

- Run `yarn run lint` to lint your code

### Prettier

- Run `yarn run format` to format your code

### Biome

- Run `yarn run check` to lint your code
- Run `yarn run format` to format your code
