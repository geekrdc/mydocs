---
title: Mac 系统推荐工具
---

以下是长期使用下来体验较好的 Mac 软件，均已原生支持 Apple Silicon。标注「免费」的均可无门槛使用，可按需挑选。

:::tip 提示
以下大部分软件都支持 Homebrew 安装，例如：`brew install --cask raycast rectangle`，批量安装更省事。
:::

## 一、系统增强

| 工具 | 说明 | 价格 |
| ---- | ---- | ---- |
| [BetterDisplay](https://betterdisplay.cn/) | 显示器管理：调节外接显示器亮度、自定义分辨率、开启 HiDPI，外接显示器必备 | 免费 + 增值 |
| [Rectangle](https://rectangleapp.com/) | 快捷键 / 拖拽到屏幕边缘分屏的窗口管理 | 免费 |
| [AltTab](https://alt-tab-macos.netlify.app/) | 让 `⌘ + Tab` 像 Windows 一样直接切换窗口并显示预览图 | 免费 |
| [Mos](https://mos.caldis.me/) | 鼠标平滑滚动，可为鼠标单独设置滚动方向，摆脱外接鼠标滚动生涩的问题 | 免费 |
| [Ice](https://github.com/jordanbaird/Ice) | 菜单栏图标收纳管理，隐藏不常用的菜单栏图标 | 免费 |
| [Stats](https://github.com/exelban/stats) | 菜单栏实时监控 CPU、内存、网络、电池等系统状态 | 免费 |

## 二、效率工具

| 工具 | 说明 | 价格 |
| ---- | ---- | ---- |
| [Raycast](https://www.raycast.com/) | Spotlight 的最佳替代：应用启动、剪贴板历史、窗口切换、Snippets，插件生态丰富，日常效率核心工具 | 免费 + 增值 |
| [Easydict](https://github.com/tisfeng/Easydict) | 开源划词翻译，支持 DeepL、有道等多个翻译源，可识别截图中的文字 | 免费 |
| [Keka](https://www.keka.io/) | 老牌压缩解压工具，支持 zip / 7z / rar 等常见格式 | 官网免费 |
| [Pearcleaner](https://github.com/alienator88/Pearcleaner) | 开源应用卸载工具，彻底清理应用残留文件，可替代收费的 CleanMyMac | 免费 |
